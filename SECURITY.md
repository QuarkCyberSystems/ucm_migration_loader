# Security policy

UCM Migration Loader moves protection data about people in vulnerable situations into Unified Case Management. Please report a vulnerability privately, never in a public issue, pull request or discussion.

## Reporting a vulnerability

Email the maintainers at **vivek@quarkcs.com** with:

- what is affected (module, command, page or API method) and the version or commit;
- the steps to reproduce it, and what an attacker could read or change;
- whether you have told anyone else.

Use synthetic data in your report. Never send real personal data, screenshots of real records or credentials.

We acknowledge reports, keep you informed while we fix them, and credit you when the fix is released if you wish.

## Supported versions

| Branch | Supported |
|---|---|
| `develop` | Yes |
| `version-16` | Yes, once released |

## Scope

The app's own code and its `ucm-push` command. Vulnerabilities in Frappe Framework itself go to Frappe: <https://frappe.io/security>.
